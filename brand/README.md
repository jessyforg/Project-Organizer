# Katha brand assets

Concept A, the banig weave: a 3×3 weave of blue and amber strips going over and under each other. Separate strands (projects, tasks, notes) are woven into one strong whole, as in a banig, the hand-woven Filipino mat. Open [preview.html](preview.html) in a browser to see every file at real sizes on light and dark backgrounds.

## Files

All files except the wordmarks and the bookmark K explorations are generated by [make-marks.py](make-marks.py) (Python, no dependencies). Change the weave there and run `python brand/make-marks.py` from the repository root.

| File                                            | Use                                                                |
| ----------------------------------------------- | ------------------------------------------------------------------ |
| `katha-mark.svg`                                | The symbol on light backgrounds (website, README, documents)       |
| `katha-mark-dark.svg`                           | The symbol on dark backgrounds                                     |
| `katha-mark-16.svg`                             | The symbol drawn on whole pixels for 16 px                         |
| `katha-mark-mono.svg`                           | One colour (`currentColor`), such as the in-app mark on the accent |
| `katha-tile-16.svg`, `-24`, `-32`               | The app icon at 16, 24, and 32 px, each drawn on whole pixels      |
| `katha-tile.svg`                                | The app icon at 48 px and up                                       |
| `katha-wordmark.svg`, `katha-wordmark-dark.svg` | Symbol plus name, for light and dark backgrounds                   |
| `explorations/`                                 | Concept B (bookmark K), kept for reference only                    |

The symbols have transparent backgrounds; the tiles are opaque by design.

## Rules

- Keep clear space of at least a quarter of the symbol's width around it.
- Use the size-specific files at 16, 24, and 32 px; the general files blur there.
- Do not recolour single strips, add effects, or set the mark on a busy image.
- The wordmark embeds Atkinson Hyperlegible Next ExtraBold (SIL Open Font License 1.1), so it renders the same everywhere.

## Not yet checked

The symbol has not been searched against registered trademarks. Before relying on it, search the USPTO and WIPO design databases for similar woven or grid marks in software (Nice class 9).
